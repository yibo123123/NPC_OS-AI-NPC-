# NPC_OS
## 面向自主虚拟生命的 AI NPC 模拟引擎


NPC_OS 是一个从零构建的 AI NPC（非玩家角色）模拟引擎。

不同于传统基于大语言模型（LLM）的聊天机器人方案，
NPC_OS 通过自主认知架构，使 NPC 具备：

- 人格系统
- 情绪演化
- 长期记忆
- 关系成长
- 目标规划
- 自主决策
- 世界模拟能力


## 核心理念

World Simulation
        ↓
NPC State
        ↓
Memory / Emotion / Relationship
        ↓
Decision Making
        ↓
Action
        ↓
LLM Language Expression


LLM 只负责语言表达，
不是 NPC 的核心智能。


## 当前版本

V12.x

包含：

- Cognitive Brain
- Memory System
- Emotion System
- Relationship Evolution
- Goal System
- Planning System
- Reflection Engine
- Self Model


## 项目定位

NPC_OS 不是聊天机器人。

目标是构建能够长期存在、
持续成长、
拥有内部状态的虚拟生命模拟系统。
