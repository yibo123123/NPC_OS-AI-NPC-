# NPC_OS

## 面向自主虚拟生命的 AI NPC 模拟引擎

NPC_OS 是一个从零构建的 AI NPC（非玩家角色）模拟系统。

不同于传统基于大语言模型的聊天机器人，
NPC_OS 致力于构建具有：

- 长期记忆
- 情绪变化
- 人格演化
- 社会关系
- 自主目标
- 行为规划

的虚拟生命模拟框架。

---

## 核心理念

NPC_OS 不追求简单对话。

目标是构建：

World Simulation →
NPC State →
Memory / Emotion / Relationship →
Decision →
Action →
Reflection

的完整认知闭环。

---

## 技术特点

- 非 LLM 驱动核心架构
- Tick-based 世界模拟
- 模块化认知系统
- 长期记忆系统
- 情绪与关系演化
- 自主目标与计划系统

LLM 仅作为语言表达层。
